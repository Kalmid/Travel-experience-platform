# Travel Experience Platform

## Project Overview
This is a mini travel experience listing platform where users can register, log in, create travel listings, and explore experiences. 
It is built as a full-stack application using React, Tailwind CSS, Node.js, Express, and MongoDB.


## Tech Stack
- **Frontend:** React 
- **Backend:** Node.js, Express  
- **Database:** MongoDB
  

## Setup Instructions

1. Clone the repository:

```bash

npm run dev

2. Start the backend:

cd server

Features Implemented

Core Features:

User authentication (Register, Login, Logout)
Create travel experience listings
Public feed displaying all listings in a responsive grid
Listing detail page with full info (image, description, location, price)
Navigation bar for authenticated users


Optional Features:

Price displayed on listing cards
Responsive mobile UI
Relative timestamps
